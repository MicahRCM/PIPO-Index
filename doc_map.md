# Average Cost After Scholarship fix (Navigator-matched average net price)
- **Problem:** VAC and CAS disagreed on the "Average" cost and neither matched College Navigator (e.g. UConn: CAS $22,844, VAC $25,097, Navigator $25,310). The 5 income bands were correct everywhere. Root cause was two different statistics: CAS computed the UNWEIGHTED mean of the 5 bands (wrong); VAC showed `avg_net_price_public`, which comes from College Scorecard `cost.avg_net_price.public` (year 2024, same year as the bands — NOT stale). Scorecard's average is provably the enrollment-WEIGHTED mean of the 5 income bands (verified to the dollar for UConn/CSUSB/UT Austin/Princeton). Navigator's headline "Average net price" is a DIFFERENT IPEDS statistic (broader aided-student population, incl. income-unreported), so it doesn't equal the weighted mean of the income bands. User chose to match Navigator.
- `data_pipeline/scrape_navigator_avg_netprice.py` -> scrapes College Navigator's reported average net price per school, matching the app's stored 5 bands to the correct year column (fallback: most-recent year). IPEDS 2023-24 (the app's newest cost year) isn't a bulk file yet, so Navigator is the only source. Output: `data/navigator_avg_net_price.csv` (1003/1004 schools; 976 matched by exact bands, 27 fallback, 1 missing).
- `data_pipeline/merge_navigator_avg.py` -> injects `metrics.avg_net_price_nav` into `web/data/institutions.json` from that CSV (idempotent).
- `web/src/lib/data.ts` -> derived `avg_net_price` now prefers `avg_net_price_nav` (Navigator), falling back to `avg_net_price_public`/`_private` when the scrape is missing a school.
- `web/src/components/cas/CasTool.tsx` -> "Average" column now uses the derived `avg_net_price` (removed the unweighted `bandAverage`), so CAS == VAC == Navigator. VAC already used `avg_net_price`.
